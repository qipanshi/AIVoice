AIVoice connects Shengzhangmen to AI tools that support MCP. With personal authorization, it reads the current user's **existing meetings, transcripts, and reports produced using Shengzhangmen devices**. This repository contains an MCP service and a command-line client (CLI / stdio bridge).

For example, an assistant can retrieve existing materials for a request such as “summarize my meetings this week and organize the action items.” The user's assistant performs the summarization; AIVoice supplies the existing records.

## Capabilities

| Capability | Description |
| --- | --- |
| MCP | Connect over Streamable HTTP and call read-only tools after personal authorization. |
| CLI | Query meetings and read existing transcripts or reports; a stdio bridge is also available for MCP clients. |
| Personal authorization | Confirm the account and permissions in the Shengzhangmen mini program; revoke access there when needed. |

**Scope:** users can only read their own existing device results. AIVoice does not upload recordings, start transcription, generate reports, or modify or delete content. The open-source license does not grant access to a Shengzhangmen account or its data.

## Quick start: MCP

1. Add this address to a client supporting **Streamable HTTP and MCP OAuth**:

   ```text
   https://open.qipanshi.com/mcp
   ```

2. Follow the client to the authorization page, scan its mini-program code with WeChat, and confirm your account and permissions in Shengzhangmen.
3. Return to the client and try reading your own meetings. Configuration differs by product and version; fields for an HTTP URL and custom headers alone do not establish OAuth support.

If a client cannot complete OAuth directly but can launch a local stdio MCP process, use the CLI bridge below. See [client guidance](docs/clients.en.md) for details.

## Quick start: CLI

Windows PowerShell:

```powershell
irm https://open.qipanshi.com/install.ps1 | iex
```

macOS / Linux:

```sh
curl -fsSL https://open.qipanshi.com/install.sh | sh
```

The installer prepares its own Node.js runtime without replacing the system installation. Network access is needed for the initial installation. Reopen the terminal, then run:

```sh
aivoice --version
aivoice login
aivoice status
aivoice meetings --limit 5
aivoice report 1001
```

`1001` is an example; replace it with an ID returned by the meeting list. Installer and CLI updates require deployment by the service operator; **code in this repository does not imply that the hosted service has already been updated**. See the [English CLI guide](docs/cli.en.md) or [Chinese CLI guide](cli/README.md) for options, authorization, uninstall, and stdio configuration.

Example stdio configuration (adapt the format to your client):

```json
{
  "mcpServers": {
    "AIVoice": { "command": "aivoice", "args": ["mcp"] }
  }
}
```

Run `aivoice login` on the machine running the client, under the same OS user and profile. Do not put tokens in shared configuration. Some Windows clients require expanded absolute paths to Node and the CLI script; see the CLI guide.

## MCP tools

| Tool | Purpose | Main arguments |
| --- | --- | --- |
| `list_meetings` | List the current user's meetings | `startDate`, `endDate`, `keyword`, `offset`, `limit` |
| `get_transcript` | Read an existing transcript in segments | `meetingId`, `offset`, `limit` |
| `get_report` | Read an existing report in segments | `meetingId`, `kind` (`standard` / `industry`), `offset`, `limit` |

Dates use `Asia/Shanghai` and include both endpoints. Meeting lists default to 20 entries, with a maximum of 50. Text segments default to 12,000 characters, with a maximum of 24,000. When `nextOffset` is returned, keep the same filters and request the next page. A report that is not ready is not generated by this service.

## Development and deployment

This repository contains MCP service **0.3.0** and CLI **0.3.1**, which have independent versions. The current CLI ZIP, tar.gz and checksum manifest are included in `downloads/`. Node.js runtime mirrors are not committed.

Service development requires Node.js 24 and npm:

```sh
npm ci
npm run check
npm run build
npm run build:cli
```

The MCP service requires a compatible business adapter to perform real account authorization and data access. Shengzhangmen's private backend, mini program, and database are outside this repository; self-hosting this repository does not itself grant access to the official service or its data. See the [deployment guide](docs/deployment.en.md) and [architecture and adapter contract](docs/architecture.en.md).
