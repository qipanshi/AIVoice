选择适合你的接入方式

第一次使用推荐先看“MCP”，无需安装程序。每个客户端按提示独立完成个人授权。

让 AI 助手连接声掌门

使用 WorkBuddy 等支持MCP 与扫码授权的工具，可直接连接，无需安装 CLI。不同工具和版本的界面可能不同。

开始前先准备

准备电脑上的 AI 工具、手机微信及声掌门账号。每位用户使用自己的账号独立授权，无需加入组织或打开组织接入开关；只能读取本人通过设备产生的已有记录。可在声掌门小程序“我的 → 开放平台”查看或解除授权。

当前服务连接测试环境；正式使用以管理员通知为准。

方法一：让 WorkBuddy 帮你接入

把下面这段话发送给 WorkBuddy。能否自动修改配置取决于其版本和权限；遇到确认提示请自行核对，扫码授权也需要本人操作。

复制后发给 WorkBuddy
请帮我接入 AIVoice 声掌门会议 MCP：
远程服务地址是 https://open.qipanshi.com/mcp。
请先检查现有 MCP 配置，保留其他服务，添加名为 AIVoiceRemote 的远程服务。

如果助手说无法修改配置、要求手动操作，或没有出现授权提示，请按下面的方法操作；不要把登录密码或访问令牌发给助手。

方法二：手动在 WorkBuddy 中添加

以下是已在当前测试环境中验证的 WorkBuddy 接入方式；其他版本界面可能不同。此方法无需先安装 CLI。

  1. 打开 MCP 配置

    在电脑上打开 WorkBuddy，进入“MCP 服务管理”，点击“添加 MCP”，打开 JSON 配置编辑界面。

  2. 添加远程地址并保存

    如果配置中还没有其他 MCP，可复制下面整段；如果已有其他服务，只将 AIVoiceRemote 项加入已有的 mcpServers，不要覆盖其他项。

    WorkBuddy · JSON 配置
    {
  "mcpServers": {
    "AIVoiceRemote": {
      "url": "https://open.qipanshi.com/mcp"
    }
  }
}

    服务地址也可以单独复制：

    MCP 地址
    https://open.qipanshi.com/mcp
  3. 使用微信扫码授权

    在 MCP 列表中找到 AIVoiceRemote，按连接或授权提示打开浏览器。使用绑定声掌门账号的微信扫码，在小程序确认权限后回到 WorkBuddy。CLI 登录不会自动授权其他客户端。

  4. 验证连接并开始使用

    在 WorkBuddy 中输入：“请用声掌门查询我最近 5 条会议，并读取其中一条已有报告。”查看工具调用是否使用 AIVoiceRemote，并将结果与小程序中的本人记录对照。首次没有记录时，先确认该账号已有设备记录和已生成报告。

使用千问工作或豆包工作？

找到 MCP 或插件管理中的 HTTP 入口，填写上面的远程地址；若支持 OAuth，按提示扫码。仅能填 URL 和请求头不一定代表支持 OAuth。如果无法授权，可以选择上方“本地 stdio 桥接”；具体工具版本需要实测。

只有 URL 和 Headers 输入框？

它不能证明该版本支持 OAuth。可改用“本地 stdio 桥接”，先在终端登录，再让工具启动桥接程序。不要在配置中填写小程序登录令牌。

在终端查询自己的会议

适合开发者、脚本和自动化流程。安装脚本自动准备独立运行环境；无需预装 Node.js 或 npm。结果以 JSON 输出，便于继续处理。

  1. 安装 CLI

    在自己的电脑终端执行对应系统的安装命令。安装到个人目录，不修改系统现有 Node.js。

    Windows · PowerShell
    irm https://open.qipanshi.com/install.ps1 | iex
aivoice --version
    macOS / Linux · 终端
    curl -fsSL https://open.qipanshi.com/install.sh | sh

    安装完成后重新打开终端，再执行 aivoice --version。安装脚本会校验下载文件，并优先从开放平台下载运行环境；平台未提供对应文件时，会提示并尝试 Node.js 官方下载站。

  2. 登录并验证连接
    首次授权
    aivoice login
aivoice status

    浏览器打开后微信扫码确认。授权保存在当前系统用户的个人目录，后续使用会自动尝试刷新。

  3. 查询与读取
    以下日期、会议 ID 为示例，请替换
    aivoice meetings --start 2026-11-01 --end 2026-11-06
aivoice transcript 1001
aivoice report 1001 --kind standard
aivoice report 1001 --kind industry

    会议 ID 从查询结果获取。返回 nextOffset 时，用 --offset 继续读取下一页或下一段。退出使用 aivoice logout。

命令参数怎么填写

先用 aivoice <命令> --help 查看该命令的完整参数。下列参数都可省略，只有读取正文时的会议 ID 必填。

适用命令参数默认与取值
所有命令--server / --profile官方 MCP 地址 / default
login--no-browser / --callback-port自动打开浏览器 / 0 自动选端口
meetings--start / --end / --keyword不设置筛选；日期 YYYY-MM-DD
meetings--offset / --limit0 / 20；每页 1–50 条
transcript / report--offset / --limit0 / 12000；每段 100–24000 字符
report--kindstandard 普通 / industry 行业
logout--local默认远端撤销；此选项仅删本地凭证

接入时，你可能会遇到

需要每次提问都扫码吗？

通常首次连接时确认一次；授权有效时可继续使用。更换工具或授权失效时，按该工具提示重新扫码。每个人必须使用自己的声掌门账号授权。

为什么提示 AIVoice 暂未开放？

这表示当前服务环境暂未启用开放平台，请联系服务维护人员确认。个人授权可在声掌门小程序“我的 → 开放平台”查看；扫码时请确认使用的是自己的账号。

AI 会自动选择声掌门吗？

AI 会根据问题及可用工具判断，并非必须包含固定关键词。如果连接了多个会议工具，可在提问中说“使用声掌门”或“使用 AIVoiceRemote”，并查看工具调用记录确认。

工作台找不到 aivoice 命令怎么办？

安装后重启工作台，让它重新加载 PATH。Windows 若不支持 .cmd 启动器，命令填写 %LOCALAPPDATA%/AIVoice/versions/<版本>/runtime/node.exe 展开后的完整路径，其中版本替换为本机实际安装版本；参数填写同版本目录下 app/dist/main.js 的完整路径及 mcp。不要把百分号变量原样填到不支持变量展开的工具里。

为什么已经登录，工作台仍提示未授权？

确认工作台和登录终端使用相同系统用户、服务地址与 profile。需要区分配置时先执行 aivoice login --profile work，工作台参数也添加 --profile work。不要复制其他人的凭证。

如何在无浏览器的服务器上登录？

CLI 的回调监听在运行 CLI 的机器上。可在自己的电脑用 SSH 转发固定回调端口，再在服务器执行 aivoice login --no-browser --callback-port 19231。请依据仓库 CLI 文档配置转发；仅把授权链接复制到另一台电脑不够。

为什么没有查到某一条会议或报告？

先确认登录账号、日期范围，以及该条记录是否属于本人并具有既有设备来源。转写、报告尚未保存时不会触发补生成；返回了 nextOffset 时需要继续读取。

开源后，任何人都能读取数据吗？

不能。MIT 许可适用于代码；读取数据需个人授权及服务端逐次校验。源码公开不代表账号、设备记录或访问令牌公开。

GitHub 链接暂时无法访问？

项目仓库公开前需要仓库访问权限。遇到接入问题可联系 50075604@qq.com，请勿发送密码或访问令牌。
